# Security Policy

## Supported versions

Security fixes are released for the latest published version only.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report them privately through [GitHub's private vulnerability reporting](https://github.com/chobitapp/chobit-csv-editor/security/advisories/new). Include a description of the issue, steps to reproduce, and the affected versions if you know them.

You can expect an initial response within a week. Once the issue is confirmed, a fix will be released as soon as possible and the advisory will be published with credit to the reporter, unless you prefer to stay anonymous.
